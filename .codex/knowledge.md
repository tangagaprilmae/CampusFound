# 5. User Experience Rules


The user should easily:


Report Lost Item:

Open Form
→ Enter Details
→ Upload Image
→ Submit


Search Item:

Search
→ Filter
→ View Results
→ Claim


Claim Item:

Select Item
→ Verify Ownership
→ Submit Request


---

# 6. JavaScript Behavior


Use JavaScript for:


- Form validation
- Modal interactions
- Mobile navigation
- Search filtering
- Image preview
- Notifications
- UI state changes


Avoid unnecessary JavaScript complexity.


---

# 7. Code Quality


Follow:


HTML:

- Semantic tags
- Accessible markup
- Clean structure


Tailwind:

- Organized classes
- Reusable patterns
- Responsive utilities


JavaScript:

- Modular functions
- Clear naming
- Maintainable code


---

# 8. UI Testing


Before completion verify:


Visual:

- Alignment
- Spacing
- Colors
- Typography


Functional:

- Buttons work
- Forms validate
- Navigation works
- Mobile layout works


---

# 9. Development Priority


When creating features:


Priority order:

1. User experience
2. Visual quality
3. Responsiveness
4. Accessibility
5. Performance


---

# Final Goal


Create a professional school platform UI that feels:

- Trustworthy
- Modern
- Simple
- Organized
- Easy for students to use
