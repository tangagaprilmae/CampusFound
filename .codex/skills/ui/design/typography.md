# Typography System


## Font

Recommended:

- Inter
- Poppins
- Manrope


## Heading

Large:

font-bold
text-4xl


Section:

font-semibold
text-2xl


Body:

text-base
text-gray-700


## Rules

Maintain:

- Clear hierarchy
- Good readability
- Proper spacing


Avoid:

- Excessive font sizes
- Too many font styles
