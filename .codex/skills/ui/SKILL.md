# UI Skill

## Purpose

Create a modern School Lost Item Reporting website interface using:

- HTML5
- Tailwind CSS
- JavaScript


## Core Design Direction

The website must follow:

- Glassmorphism style
- Modern dashboard aesthetic
- Smooth interactions
- Responsive layouts


## Development Approach

Use:

HTML:
- Semantic structure
- Accessible elements
- Clean markup


Tailwind CSS:
- Utility-first styling
- Responsive classes
- Consistent spacing


JavaScript:
- Dynamic interactions
- Form validation
- UI state handling


## Coding Standards

Follow:

- Reusable components
- Clean class organization
- Meaningful naming
- Avoid duplicated code


## File Structure

Recommended:

components/
- navbar.html
- card.html
- modal.html

pages/
- dashboard.html
- search.html

js/
- app.js
- validation.js

css/
- input.css
