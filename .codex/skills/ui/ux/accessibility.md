# Accessibility Rules


The UI must support:


## Semantic HTML

Use:

<header>
<nav>
<main>
<section>
<footer>


## Forms

Every input needs:

- Label
- Placeholder
- Error message


## Keyboard Support

Ensure:

- Buttons are reachable
- Focus states visible


## Visual Accessibility

Maintain:

- Text contrast
- Readable font sizes
- Clear icons
