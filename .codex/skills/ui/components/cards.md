# Card Component Skill


Cards are used for:

- Lost items
- Found items
- Dashboard statistics
- User reports


## Design


Required:

- Rounded corners
- Glass effect
- Hover animation


Example:

```html
<div class="
p-6
rounded-3xl
bg-white/20
backdrop-blur-xl
border
border-white/30
hover:scale-105
transition
">
</div>
