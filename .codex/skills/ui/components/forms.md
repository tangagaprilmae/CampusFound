# Form Component Skill

## Purpose

Create clean, modern, user-friendly forms for the School Lost Item Reporting Website.

Forms are used for:

- Lost item reporting
- Found item reporting
- Claim verification
- User profile updates
- Search filters


---

# Form Design Principles

Forms must be:

- Simple
- Easy to understand
- Mobile-friendly
- Visually consistent
- Fast to complete


Users should be able to submit a report within a few minutes.


---

# Form Layout

Use a card-based glassmorphism container.


Example:

```html
<form class="
bg-white/20
backdrop-blur-xl
border border-white/30
rounded-3xl
p-6
shadow-lg
">

</form>
